# rollnull

Roll HTML/Markdown null fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/rollnull/

## Install / run

```bash
git clone https://github.com/theworker02/rollnull.git
cd rollnull
node src/cli.js
node --test
```
